# Selected NOCI: `snoci`

The `snoci` table runs [selected NOCI and NOCI-PT2](../methods/selected.md) over the candidate
space generated by [`excit`](excit.md).

```lua
snoci = {
    sigma = 1e-6,
    tol = 1e-8,

    max_iter = 100,
    max_add = 5,
    max_dim = 100,

    preconditioner = "woodbury",
    imag_shift = {0.0},

    full_m = "none",
    factor_tables = "ram",

    gmres = {
        max_iter = 100,
        restart = 200,
        res_tol = 1e-8,
    },
}
```

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `sigma` | number | `1e-6` | Selection threshold on each candidate's perturbative score. |
| `tol` | number | `1e-8` | Stop when the magnitude of the NOCI-PT2 correction falls below this, in $E_\text{h}$. |
| `max_iter` | integer | `100` | Maximum SNOCI iterations. `1` gives a NOCI-PT2 calculation. |
| `max_add` | integer | `1` | Maximum determinants added per iteration. |
| `max_dim` | integer | `100` | Maximum size of the selected space. |
| `imag_shift` | list of numbers | `{0.0}` | Imaginary level shifts. NOCI-PT2 is evaluated for each; the **last** drives selection and convergence. Any nonzero shift switches to complex arithmetic. An empty list means `{0.0}`. |
| `preconditioner` | string | `"woodbury"` | GMRES preconditioner: `"none"`, `"diag"` (inverse diagonal of the projected operator) or `"woodbury"` (diagonal plus a rank-2 correction for the projection). `"none"` skips building the diagonals. |
| `full_m` | string | `"none"` | Store the full candidate–candidate operator $\mathbf M$: `"none"`, `"ram"` or `"disk"`. With `"none"`, products are formed on demand from the factorised tables. |
| `factor_tables` | string | `"ram"` | Storage of the spin-factorised one-body tables used when `full_m = "none"`: `"none"`, `"ram"` or `"disk"`. |
| `gmres.max_iter` | integer | `100` | Maximum GMRES iterations per solve. |
| `gmres.restart` | integer | `200` | GMRES restart dimension. |
| `gmres.res_tol` | number | `1e-8` | GMRES residual RMS tolerance. |

Disk files for `full_m` and `factor_tables` are written to [`wicks.cachedir`](wicks.md). SNOCI
runs with real and holomorphic references; holomorphic references always use complex arithmetic.
